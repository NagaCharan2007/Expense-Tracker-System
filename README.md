# Expense Tracker System

## Project Description

Expense Tracker System is a console-based Core Java application developed to help users record, manage, and analyze their personal expenses.

## Features

* Add Expense
* View Expenses
* Update Expense
* Delete Expense
* Expense Categories
* Expense Reports
* Data Persistence using File Handling
* Error Handling

## Technologies Used

* Java
* OOP Concepts
* ArrayList
* File Handling

## Project Structure

* Expense.java
* ExpenseTracker.java
* FileManager.java
* ReportGenerator.java

## How to Run

1. Compile all Java files
2. Run ExpenseTracker.java
3. Select options from the menu
